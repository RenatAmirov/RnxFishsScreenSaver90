# Аквариум 90

Экранная заставка для Windows в духе аквариумов 90-х и 2000-х. Золотые рыбки, дискусы, скалярии, синие хирурги, неоны и гуппи плавают среди водорослей и коряг. Рыбки двигают хвостами и разворачиваются, пузырьки поднимаются со дна, а у поверхности колышутся блики. Заставка работает без звука и сети.

## Запуск и установка

Готовая сборка для Windows x64: `dist/win-x64/Аквариум 90.scr`. Для разового запуска дважды щёлкните файл. Для установки переместите его в папку, где он будет храниться постоянно, затем нажмите правой кнопкой мыши и выберите **Установить** (в Windows 11 пункт может находиться в меню **Показать дополнительные параметры**). В открывшемся окне Windows задайте время ожидания и нажмите **Применить**. Положение файла после установки следует сохранить: Windows запускает заставку по её пути.

Кнопка **Параметры** в диалоге Windows открывает живой предпросмотр, где можно поменять количество рыб, скорость плавания и включить или выключить пузырьки. Кнопка **На весь экран** позволяет попробовать текущие настройки сразу. Чтобы сохранить их для следующих запусков, нажмите **Сохранить настройки**. Нажатие клавиши, щелчок или движение мыши завершает полноэкранный режим.

## Сборка из исходников

Нужны Windows и SDK .NET 10. Приложение написано на C# и WinUI 3, сцена и анимация рисуются в Win2D. Фон и спрайты рисуются по коду проекта и кешируются; внешних изображений и сетевых запросов нет.

```powershell
dotnet build
dotnet run -- /window
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
```

Скрипт собирает автономный `.scr` с .NET и Windows App SDK внутри, так что пользователю не нужно устанавливать их отдельно. При первом запуске .NET распаковывает компоненты во временную папку. Для сборки под Windows Arm64 передайте скрипту `-Runtime win-arm64`.

| Аргумент | Что делает |
| --- | --- |
| `/s` | Запускает заставку на всех подключённых мониторах |
| `/c` или `/c:HWND` | Открывает окно настроек |
| `/p HWND` или `/p:HWND` | Рисует миниатюру внутри диалога Windows |
| `/window` | Запускает аквариум в обычном окне |
| Без аргументов | Открывает окно настроек при запуске из командной строки |

Настройки хранятся в `%LOCALAPPDATA%\Aquarium90\settings.json`.

Справка: [параметры запуска экранных заставок](https://learn.microsoft.com/en-us/previous-versions/windows/desktop/ms686421(v=vs.85)) и [автономная публикация WinUI 3](https://learn.microsoft.com/en-us/windows/apps/package-and-deploy/unpackage-winui-app).
